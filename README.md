# Commit Leaderboard

Stack skeleton for the Commit Leaderboard app.

## Development

Run the Next.js dev server with pnpm:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Run the local checks:

```bash
pnpm run typecheck
pnpm run lint
pnpm run convex:deploy-once
```

## Stack

- Next.js App Router
- Clerk authentication
- Convex backend
- Tailwind CSS
